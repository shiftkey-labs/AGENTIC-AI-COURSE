# Final Assignment: Create an AI Agent

**Due date:** October 13th at 11:59PM

## Project Overview

In this assignment, you will design, develop, and evaluate an AI agentic system that addresses a real-world problem. This project is for us to evaluate your learning in agentic AI concepts and provide hands-on experience with autonomous AI systems.

## Project Requirements

### 1. Problem Identification & Agent Development

**Target**: Create a functional AI agentic system that solves a specific, well-defined problem. This problem can be a problem that you have, a problem that your friend has or a problem that a business has.

**Acceptable Platforms**: Students may use any no-code/low-code platforms (we suggested n8n) or even coding approaches. The focus is on agent design and behaviour, not technical implementation complexity.

### 2. Deliverable Components

#### Description & Explanation
- Clear problem statement and justification for an agentic solution
- Target audience and use case definition
- Expected outcomes and success criteria

#### Agent Development
- System architecture overview (visual diagrams encouraged)
- Agent capabilities, tools, and decision-making processes
- Implementation approach and platform justification
- Screenshots/demonstrations of the working system

#### Behavioral Evaluation
- Analysis of agent strengths and limitations
- Multiple agent execution path (avoid golden path)

#### Conclusion
- Summary of key findings and project outcomes
- Assessment of whether objectives were met

#### Recommendations
- Suggestions for system improvements
- Potential risks
- Next steps for the project or the next developer

#### Insights & Reflections
- Personal learning outcomes
- Challenges encountered and lessons learned
- Implications for future agentic AI applications

## Submission Format

**Video submission:** 10-minute walkthrough of your AI agent, including all of the deliverable components.
